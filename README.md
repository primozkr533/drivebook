# DriveBook

Test-drive and viewing bookings for Slovenian car dealers — drivebook.si.

## Run

```sh
docker compose up --build    # http://localhost:3000/design
# or
npm install && npm run dev
```

The `/design` route is the design-system showcase (tokens, primitives, signature components, sample screens).
See `CLAUDE.md` → *Design system* for the rules every screen follows.
